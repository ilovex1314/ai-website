# 口播课程动画制作台：Manifest-first 教学案例

## 人设与语气

- 29 岁互联网女性，像在向朋友复盘自己最近做的生产力工具。
- 自然、清楚、有产品判断，不使用发布会口吻。
- 推荐语速约 245-265 字/分钟，关键词稍停顿。

## 故事线

1. 先展示结果：口播、PPT 和教学标注可以在同一个工作台组装。
2. 解释产品拆层：后台、前台、平台覆盖动画。
3. 展示完整生产流程：项目复盘到成片和剪辑交付包。
4. 解释为什么改成 manifest-first：元素与动画在生成时就带结构化描述。
5. 解释编辑模型：内置动画可修改、禁用、恢复；同一元素可分时段绑定多个动作。
6. 总结价值：快速初始化、所见即所得、可继续交给 Codex 和剪辑软件。

## 录制提示

- 开场先说“怎么做”和“得到什么”，不靠夸张冲突吸引注意。
- “后台、前台、覆盖动画”三层要慢一点，让听众建立模型。
- 讲 manifest 时用“视频的说明书”做口语化解释。
- 横屏真人口播后续放在右下角，画面主体不要遮挡右下安全区。
