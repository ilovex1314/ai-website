# 动作库单元素实时 Demo 设计

## 目标

动作库子页面在选中任一动作后，于右侧展示该动作作用于单个课程元素的真实效果。Demo 只帮助用户判断动作本身，不模拟整张 PPT 或完整视频合成。

## 交互

- 动作资产行改为可选择按钮，并显示明确选中态。
- 右侧固定为 Demo 面板；舞台中只有一个中性的课程元素和当前动作。
- 首次进入默认选中第一个动作；切换动作立即重播。
- 提供播放/暂停与重播按钮，显示当前动作名称、类别、实现模式、默认时长和关键参数。
- Demo 使用有限循环，不持续无限运动；开启 `prefers-reduced-motion` 时保持最终状态。

## 实现边界

- 新建独立 `CourseActionLiveDemo` 组件，避免继续扩大子页面组件。
- 复用动作 schema、默认参数和主工作台已有的 `preview-action--<category>` 样式。
- Demo 舞台使用百分比布局，动作只围绕单元素展示；不读取后台视频、element map 或 timeline。
- 本次不提供参数编辑、导出和复杂 LLM 动作在线编译。

## 验收

- 选择高亮、圈注、箭头、进度、代码等动作时，右侧 Demo 内容与类别同步变化。
- 重播会重新触发该动作，暂停会冻结当前状态。
- 列表与 Demo 可通过键盘访问，动作名称不会溢出容器。
- `npm test -- --run` 与 `npm run build` 通过，并在浏览器中完成真实点击验证。
