# 动作资产分类与“指向”设计

## 决策

动作资产面向用户拆为两类：

1. **添加动画**：依附已有 PPT DOM，改变该元素或围绕该元素产生强调效果。
2. **添加元素 + 动画**：平台创建新的覆盖 DOM，再为其配置出现、持续和退出动画。

`parametric`、`llm-assisted`、`custom-component` 继续作为内部实现元数据保留，但不再占用动作库主列表列位。动作库主列表展示“资产类型”和“动作分类”。

## 分类规则

- 添加动画：高亮框、圈注、局部聚焦、代码行高亮、前后对比、遮罩聚光、HyperFrames 扫光。
- 添加元素 + 动画：流程箭头、重点文字卡、章节标题条、课程进度条、步骤提示、光标提示、章节转场、指向。

## “指向”资产

“指向”是添加元素 + 动画资产。用户先选择 PPT 目标 DOM，再添加指向箭头。箭头尖端锚定目标 DOM 的最近边缘，尾部位置和整体尺度通过画布拖拽与缩放调整。

可配置项：

- 形状：直线、曲线、折线、自定义图片。
- 位置：尾部相对目标 DOM 的偏移，画布拖拽更新。
- 大小：画布缩放手柄更新箭头长度和占位范围。
- 颜色：内置箭头跟随颜色选择器；自定义图片保留原色。
- 时间：开始帧、持续帧、淡入帧、淡出帧。

## 自定义箭头

- 接受透明 `PNG`、`WebP`、`SVG`。
- SVG 导入时移除脚本、事件属性、`foreignObject` 和外部 URL。
- 上传后用户依次在预览图中标定尾部和尖端，保存为 0–1 归一化双锚点。
- 渲染时使用保持比例的旋转与缩放，把素材尾部/尖端映射到当前箭头向量。

## 验收

- 动作库可按资产类型筛选，主列表不再展示实现 mode。
- “指向”在动作库实时 Demo 中支持三种内置形状和自定义图片。
- 主工作台选中目标 DOM 后可绑定“指向”，配置颜色与时间，并在画布拖拽/缩放。
- 箭头在 16:9、4:3、9:16 下始终锚定目标 DOM。
