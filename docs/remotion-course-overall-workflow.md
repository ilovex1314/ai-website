# Remotion Course Workbench Overall Workflow

The right shape is a repo-owned production workflow:

1. Build the website management console first.
2. Let Remotion consume the same timeline model.
3. Export universal handoff packages for CapCut/Jianying.
4. Keep Codex automation as project-owned schema, prompts, examples, and scripts before turning it into a formal skill.

This prevents the system from becoming a one-off Remotion demo or a fragile CapCut automation hack.
